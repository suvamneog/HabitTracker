# HabitTrack - A Modern Habit Tracking Application

## Overview

HabitTrack is a feature-rich habit tracking application built with React, TypeScript, and Tailwind CSS. It helps users build and maintain positive habits through visual progress tracking, streak monitoring, and detailed analytics.

![HabitTrack Screenshot](/Users/suvamneog/Desktop/project 3/habittracker.png) *(Replace with actual screenshot URL)*

## Features

- **Habit Management**
  - Create, edit, and delete habits
  - Set daily/weekly goals with custom units
  - Track progress with visual indicators
  - Mark habits as complete/incomplete

- **Progress Tracking**
  - Daily streak counters
  - Best streak records
  - Completion percentage tracking
  - Visual progress charts

- **Analytics**
  - Weekly habit completion charts
  - Monthly calendar view with completion heatmap
  - Detailed habit statistics
  - Category breakdown

- **User Experience**
  - Dark/light mode toggle
  - Responsive design for all devices
  - Animated transitions
  - Interactive UI elements

- **Account Features**
  - Notification settings
  - Data export options
  - Profile management

## Technologies Used

- **Frontend**
  - React with TypeScript
  - Tailwind CSS for styling
  - Framer Motion for animations
  - Lucide React for icons
  - Recharts for data visualization
  - date-fns for date handling

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/habittrack.git
   cd habittrack
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser to `http://localhost:3000`
